What  each one is for:
| Library      | Used for                                  |
| ------------ | ----------------------------------------- |
| `pandas`     | Loading and analyzing the banking dataset |
| `numpy`      | Numerical calculations                    |
| `matplotlib` | Data visualization                        |
| `seaborn`    | Statistical visualizations                |
| `jupyter`    | Running the `.ipynb` notebook             |
